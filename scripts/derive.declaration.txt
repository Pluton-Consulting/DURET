# Une entree par ligne :   <chemin ou motif>   # <raison>
# `*` ne traverse pas les `/`, `**` les traverse, un motif fini par `/` couvre
# tout le sous-arbre. Les sections [nom] sont pour la lecture humaine.
#
# LA REGLE D'ADMISSION, et elle est stricte :
#   on declare le fichier qui PORTE LA MARQUE PAR DESTINATION - la charte, le
#   logo, le prompt d'identite, le connecteur du socle documentaire d'un client,
#   le fichier de deploiement d'un client.
#   on ne declare PAS un fichier du socle commun qui a seulement attrape un mot
#   de marque au passage, ni un fichier ou un correctif n'a ete pose que d'un
#   seul cote. Ces deux-la doivent converger, et le compteur doit continuer a
#   les montrer.
#
# Toute entree ajoutee ici fait baisser le chiffre sans qu'une ligne de code ait
# bouge. C'est un budget qu'on depense, pas un menage qu'on fait. Une raison
# ecrite est donc obligatoire : sans elle, personne ne saura, dans six mois, si
# la ligne protege une decision ou couvre un oubli.
#
# Une entree qui ne designe plus aucun fichier est signalee par le compteur
# comme « sans objet » : c'est une bonne nouvelle, elle est a retirer.
